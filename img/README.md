# Фото сайта — как заменить

Каждое фото лежит в слоте с постоянным именем. Чтобы поменять картинку на сайте,
положите новый файл **с тем же именем** в эту папку — код трогать не нужно.

Формат — JPG. Размер по длинной стороне — 1400–1920 px, вес до 400 КБ.
Сейчас в слотах стоят временные фото для примера.

## Чего не хватает больше всего

1. **Зимний пар над термами** — самый сильный кадр для термального курорта, сейчас его нет вообще.
2. **Ауфгусс-шоу** — банщик с полотенцем, пар, свет.
3. **Дом-контейнер в хорошем разрешении** — текущий всего 605 px, на больших экранах мылит.
4. **Интерьеры домов** — для каждого из трёх типов.
