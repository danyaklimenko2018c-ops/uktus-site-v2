# Баден-Баден Термы Уктус — сайт, версия 2

Тестовая версия с новой структурой. Оригинал (`anastasiafrolova933-sys/DaniilK-baden-uktus`) не тронут.

## Структура — 6 разделов, у каждого одна задача

| № | Раздел | Что внутри |
|---|---|---|
| 01 | **Термы** | Тарифы · акции и абонементы · **карта лояльности** · бани и ауфгуссы · бассейны · калькулятор |
| 02 | **СПА** | Пакеты «Термы + СПА» · прайс по группам · запись |
| 03 | **Кафе и бары** | 5 заведений · меню по каждому · завтраки · «Романтический вечер» |
| 04 | **Анимация** | Детям · авторские парения по субботам · программы для компаний · группы |
| 05 | **Проживание** | 3 типа домов · что включено · акции на проживание · бронирование TravelLine |
| 06 | **Информация** | Контакты · как добраться · схема · вопросы · сертификаты · все документы |

**Правило:** каждая цена и каждое расписание указаны на сайте ровно в одном месте.
Где информация нужна в другом разделе — там ссылка, а не копия.

## Программа лояльности

Вкладка «Карта лояльности» в Термах — по правилам программы «BADEN UKTUS» от 31.05.2026.
Кнопка ведёт в бота @BadenLoyalty_bot; сам бот и его сервер сайт не трогает.
Скидка действует только на входной билет, поэтому живёт в Термах, а не отдельным разделом.
Калькулятор сравнивает карту с акциями и показывает самый выгодный вариант — как на кассе.

## Шрифт

**Gilroy** (Радомир Тиньков), шесть начертаний 300–800, свои файлы в `assets/fonts/` (WOFF2, 155 КБ).
Google Fonts не используется — сайт не делает внешних запросов за шрифтами.
Подстройку заголовков включает атрибут `data-font="gilroy"` на `<html>` — не удалять.

⚠️ Gilroy — коммерческий шрифт. Для публикации нужна **веб-лицензия** (настольная лицензия встраивание на сайт не покрывает).

## Как поменять цены, расписание, телефоны

Всё лежит в одном файле — **`assets/data.js`**. Открыть в любом редакторе, поменять число, сохранить.
Раздел сайта подтянет новое значение сам.

После правок увеличьте версию в `index.html` (например, `?v=1023d` → `?v=1024a`) —
иначе у гостей может остаться старая версия из кеша браузера.

## Как поменять фото

Положить файл с тем же именем в `img/`. Список слотов и что в каждом нужно — `img/README.md`.

## Файлы

```
index.html        разметка и тексты разделов
assets/data.js    ВСЕ цены, меню, расписания, контакты, документы
assets/app.js     вывод данных и интерактив (вкладки, калькулятор, расписание)
assets/style.css  оформление, светлая и тёмная тема
img/              фото в именованных слотах
map.html          интерактивная схема комплекса (перенесена из оригинала)
```
